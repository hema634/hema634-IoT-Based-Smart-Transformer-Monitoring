
# Working Principle

## 1. Introduction

The proposed IoT-based smart transformer monitoring system continuously monitors important transformer operating parameters using sensors and an ESP32 microcontroller.

## 2. Voltage Monitoring

A suitable voltage sensing circuit measures the transformer's voltage and provides a safe, scaled signal to the controller.

## 3. Current Monitoring

A current sensor measures the load current flowing through the transformer circuit.

## 4. Temperature Monitoring

A temperature sensor monitors the transformer's temperature to identify abnormal thermal conditions.

## 5. Data Processing

The ESP32 receives sensor readings, processes the measurements and prepares the data for transmission.

## 6. Wireless Communication

The ESP32 uses Wi-Fi to transmit monitoring data to a cloud platform.

## 7. Cloud Monitoring

The cloud platform stores the received data and makes it available through a monitoring dashboard.

## 8. Alert Generation

The system can compare sensor readings against configured operating limits and generate alerts when abnormal conditions are detected.

## 9. Conclusion

This proposed system aims to improve transformer monitoring through sensor-based measurement, wireless communication and remote data visualization.
