
# Hardware Components

## 1. ESP32 Microcontroller

The ESP32 is the main controller of the proposed system. It receives sensor readings, processes the data and sends information to the cloud using Wi-Fi.

## 2. Voltage Sensor

A suitable voltage sensing module is used to measure the transformer's voltage. The sensing circuit must provide appropriate electrical isolation and signal conditioning.

## 3. Current Sensor

A current sensor measures the electrical current flowing through the monitored transformer circuit.

## 4. Temperature Sensor

A temperature sensor measures the thermal condition of the transformer.

## 5. Wi-Fi Communication

Wi-Fi provides wireless communication between the ESP32 and the cloud platform.

## 6. Cloud Dashboard

The cloud dashboard displays voltage, current and temperature readings for remote monitoring.

## 7. Summary

These components form the proposed hardware and communication architecture of the IoT-based smart transformer monitoring system.

## Safety Considerations

- Use appropriately rated voltage sensing circuits.
- Provide electrical isolation.
- Protect the controller from electrical faults.
- Calibrate sensors before measurement.
- Do not connect high-voltage transformer terminals directly to the ESP32.
